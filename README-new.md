Interface web interativa, publicada no GitHub Pages, para explorar modelos de cerâmica em 3D, personalizar materiais e comparar acabamentos. Em dispositivos compatíveis, permite visualizar as peças em realidade aumentada.

<p align="center">
  <img src="assets/interface/interface-ar-ceramic-designer-v3.webp" alt="Interface do AR Ceramic Designer" width="50%" />
</p>

## Tecnologias

| Tecnologia | Utilização |
| --- | --- |
| TypeScript | Linguagem principal, com tipagem estática. |
| React | Interface e componentes da aplicação. |
| Three.js | Renderização e interação com modelos 3D. |
| Vite | Desenvolvimento e build da aplicação. |
| WebXR | Experiência de realidade aumentada em dispositivos compatíveis. |

## Executar localmente

```bash
cd app
npm install
npm run dev
```

## Demo

[Acessar a aplicação](https://lianeheidemann.github.io/ar-ceramic-designer/)

A realidade aumentada requer um dispositivo Android compatível com WebXR.
